   - Upstream `packages/core/system-prompt` and `packages/core/agent-loop` now emit an initial leading `system/message` with one `TextBlock` per section and append mid-conversation incremental `system/message` updates instead of rebuilding the head system prompt.
   - `src/host/common/llm-compat.ts` widens `MessageSource` with optional `complete`, `reset`, and `sections`, adds `extractSystemText` (`\n\n`-joined), `leadingSystemEndIndex`, `formatMidConversationSystemReminder` (escaping `</system-reminder>` to `<\/system-reminder>`), and `midConversationSystemToUserMessage`, and updates `normalizeMessages` to join multi-block `system` messages with `\n\n`.

   - `src/host/plan-mode-cache-guard.ts` strips both `plan:policy` and `plan:status`, ignores `retire: true`, and uses `plan:status` (`status.trim() !== '' && !/\binactive\b/i.test(status)`) when present so exiting plan mode never re-delivers persistent `plan:policy`.
   - `src/host/team-policy-cache-guard.ts` routes `retire: true` through the revocation path; `src/host/timeline-cache-guard.ts` and `src/host/ptc-sdk-cache-guard.ts` pass through `retire: true` sections and clear stale frozen cache entries instead of overwriting retirement notices.
3. **`ImageRequestTarget` contract rename (`@deepseek-ai/dsh-attachment@0.2.3-alpha.1` — compile-breaking)**:
   - Upstream replaced `maxImageBytes` / `imageTargetBytes` with `maxBytes` on `ImageRequestTarget`.
   - `src/host/common/request-images.ts` (`CompatImageRequestTarget`, `requestImageTarget`, `requestImageTargetOrOriginal`), `src/host/kimi-code/adapter.ts`, and `src/host/claude/mapper.ts` emit all three byte-limit keys (`maxBytes`, `maxImageBytes`, `imageTargetBytes`) simultaneously alongside `maxPixels` on resized targets.

   - Upstream stopped writing `subagent/model-selection-policy` session events and instead serves live allowlists via `ctx.subagentModelSelection.allowedRoutes()` (throwing `INVALID_MODEL_SELECTION_SETTINGS` on invalid enabled configs).
