  `FactoryOutlet` memoizes `nextAncestors` with `useMemo`. Zero API or contract
  deltas affecting the plugin.

  Adds additive exports `UserQuestionRecord` and `UserQuestionPanels`, and
  extends the `@deepseek-ai/cordis` Context interface with optional
  `userQuestionPanels`. All existing exports and slot contracts
  (`ToolCallViewProps`, `StartedToolCallViewProps`, etc.) are 100% unchanged.
- **`tool-ask-user`** — `src/index.ts`, `timed.ts`:
  Adds `registerTimedAskUser` and an optional `Config.mode` (`'legacy' | 'timed'`).
  Defaults to `'legacy'`, preserving existing blocking behaviour by default.
  Fully backwards compatible.

  Updated prompt descriptions advising models to verify resolved paths before
  deleting or moving files and not to assign to automatic variables such as `$HOME`.
- **`agent-preset`** — documentation update only (`cordis-composition-reference`).
